Sender's color

Recording and playback use the same press times, so both devices show the same motion. "Not received" is the only other color: a red pulse when no receipt comes back.

Case

0 is bare LEDs seen as twelve small dots; higher makes each LED a wider, softer circle of light until they merge. This only changes the drawing, not the firmware.

The same light over a wider circle is dimmer at its center, as it would be in the case. Use it to judge how much smoothing the case needs before the comet reads as one moving light.

Tuning

Send these numbers back to change the firmware's defaults. The current shown is an estimate from the LED values, held under the budget by dimming a whole frame when it would go over.
